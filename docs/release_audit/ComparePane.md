# Compare pane — release audit

## 1. Purpose and how it is reached

The Compare pane is the compare-and-merge suite Adam asked for on 2026-09-08 ("bring Beyond Compare, WinMerge, UltraCompare and Araxis Merge's combined functionality into our translation tool"). It compares two Tibetan or English texts line by line with syllable-level in-line marks, merges between them, compares two folders, and merges three texts (base + two edits). It is `class ComparePane` in `app/compare_pane.inc` (included from `app/main.cpp` before `FilesPane`), built on the `allcore::textdiff` engine (`core/src/textdiff.cpp`, battery `textdiff_smoke`). It sits in the **Research** group as the tab **"Compare"** (`mkGroup("Research", {… "Analysis", "Compare"})`), and is also reached from Tools ▸ Compare ▸ …, from the Files pane's context menu ("Compare with the other side's selection", "Compare the two selected"), and from the `--compare <left> <right> [report]` command line. Feature matrix and verdicts: `docs/COMPARE_SUITE_PLAN.md`.

## 3. Honesty and provenance
- Nothing is written to disk until Save; folder sync previews and confirms; nothing is ever deleted.
- "Minor" is exactly what the switched-on rules define; the minor count is always shown beside the important count.
- Script-agnostic comparison uses only the canonical converters; unconvertible lines are compared raw and counted.
- Binary files never get a text diff.

## 5. F0 substrate (2026-09-09)
- The folio marker is defined once (`allcore/textspan.h`, `@([0-9]{1,4}[AaBb]?)(?![A-Za-z0-9])`) and every site uses it: `textdiff` normalisation and citations, Properties statistics, Insert ▸ Folio Marker, Selection ▸ Folio, Goto ▸ Folio. Consequence, stated: Properties' folio count now also counts `@1A` and bare `@0012` markers, which the old 2–3-digit-plus-letter regex missed; Goto ▸ Folio accepts them too.
- `allcore/filewalk.h` is the one eligibility rule (`.txt .acip .md .act .inc .ace`, ≤ 10 MB) — Search and the library index call it; Replace in Files will.
- `textdiff::applySelected` is the hunk-selection primitive for partial merges.
- Compare with Saved Version flattens the Manuscript's saved HTML before comparing.
- The constitution's modal census now reads `app/*.inc` as well; a planted `QMessageBox::warning` in `compare_pane.inc` fails the gate (checked by hand 2026-09-09).
