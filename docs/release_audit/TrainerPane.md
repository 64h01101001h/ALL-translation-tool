# TrainerPane — release audit

`app/main.cpp` lines 18240–18643. Audited 2026-09-08 against the source only; no files were modified.

## 1. What it is

`TrainerPane` is the **Translation Trainer**: a graded-reveal reading exercise. The learner pastes an ACIP (or Wylie — auto-detected) Tibetan passage into a small text box, presses **Load**, tries to read it unaided, then ticks up to six numbered checkboxes to reveal successive layers of help — chunking, particle roles, reading order, vocabulary, the HGM corpus answer key, and a full Wilson-designation parse. Its banner states the pane's honesty contract verbatim: *"Engine guidance is labeled guidance; only HGM corpus lines are answers."* It is a **top-level tab** of the main window, added as `tabs.addTab(trainerPane, "Trainer")` at `app/main.cpp:35859`, constructed at 35857–35858 with `(spine, progress, poslex, contractions)` — it sits in the main tab bar between **Analysis** (35856) and **Drills** (35861), i.e. in the pedagogy cluster. The user reaches it by clicking the "Trainer" tab; there is no menu item, shortcut, or deep link into it.

## 5. Release questions

- **The deck promise.** The coverage note tells the user "words you click join the deck", but no code in this class writes to `Progress`. Either wire the click-to-deck path or change the wording before release — as it stands it is a false statement in the UI.
- **Silent Tibetan-script fallback.** `tokensText()` throws away the `ok` flag from `wylieToUnicode` and silently prints the roman token instead (18379–18381). Inviolable rule 3 says failed conversions are flagged. Decide: flag with the `⟨wylie⟩` marker convention, or record an explicit exemption.
- **`[PROVISIONAL]` and honorific tags are untested.** The pane's honesty labels are rendered but no self-test check asserts they appear. Add a check, or manually verify against a known provisional entry before shipping.
- **Answer-key layer has zero direct coverage.** Nothing asserts that a corpus hit ever renders, or that it is labeled `HGM:`. Manually verify with a passage known to be in the 42,199-segment corpus.
- **Empty/failed states are mute.** An unparseable passage, an empty `wilsonParse`, and an empty box all render identically (blank). Confirm this is acceptable or add a "couldn't read this passage" message.
- **Privacy of `sess/trainer/source`.** The user's pasted study passage persists in QSettings indefinitely. Confirm this is intended and that there is a way to clear it.
- **Layer isolation in the self-test.** Layers 1, 2, 4, 5, 6 are only ever tested with all six boxes ticked at once. Consider whether suite 38 should assert each layer independently (the same defect class SQA TEST-5 was written to catch for `script_`).
- **No tooltips on the six numbered layers.** Decide whether the terse labels ("2 · particle roles") suffice for a learner-facing pane, given the design wing's discoverability rules.
