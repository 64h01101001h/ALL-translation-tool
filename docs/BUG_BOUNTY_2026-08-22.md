## Systemic themes

1. EVERY HIGH-RANKED DEFECT IS A COPY OF A SOLVED PROBLEM WITH THE SOLUTION MISSING. attestedEnglish() enforces the equality test in the pecha exporter and the four-layer view omits it; warnWriteFail is honored at 10 sites and skipped at 4 (19 bare open+write sites against 10 warnings); HuntPalette lane 1 appends [PROVISIONAL] and lane 3 does not; titleBank() reports its size and carries a comment saying why, while the QC bank does not; moveToShelf rolls the rename back on META failure and applyComposedName orphans it; showMeterReader refreshes its jumppos anchors on textChanged and showCitations does not; five browsers pair setOpenLinks(false) with an http branch and CatalogPane does not. The house has correct rules and no mechanical enforcement, so each rule holds only where its author remembered it. The fix is not 14 patches — it is one shared helper per rule plus a CI grep or a type that makes the wrong version unwriteable. 2. HONESTY IS ENFORCED AT THE RENDER SITE INSTEAD OF IN THE DATA. Entry::provisional() is a bool any of ~20 render paths can forget, and three did. A gloss should not be a bare std::string that anyone can print; it should be a type that carries its tier and cannot be converted to display text without one. Same for counts: a rendered number should come from a COUNT query, never from .size() of a LIMITed result. 3. COMMENTS AND MANUAL ARE THE SPEC, WRITTEN FIRST AND NEVER RECHECKED AS THE FEATURE GREW. \"the cap never hides the true total\" sits directly above the code that prints 200 of 200; \"English appears only where the exact line is attested\" above the code that prints a containing segment's English; \"refuses rather than overwriting anything\" above the META clobber; the two-up message predates layouts 3 and 4; USER_MANUAL.md promises the tooltip shows Geshe Michael's English. In this codebase a nearby comment asserting an invariant is a reliable smell that the invariant is violated — the comment records the intent at authoring time and nothing re-derives it. Comments claiming completeness or authority should be treated as assertions requiring a test. 4. I/O REPORTS INTENT, NOT RESULT. Return values of open, write, rename, mkpath and stampFolder are routinely discarded; success HTML is composed unconditionally after the attempt; counters increment on the wrong branch so a whole failure class (fetched-but-unsaved) is neither counted nor visible; a truncated file then re-enters as \"already present\". Rule to adopt: nothing prints a success string that was not produced by the code path that verified the bytes landed. 5. THERE IS NO CHOKEPOINT FOR \"THE DOCUMENT CHANGED.\" State lives in parallel members (docFile_, glossary_, fileKey_, scanWork_, lastFile_) mutated by whichever path ran, so a second entry point produces split identity (Overlay's own open button), a rename orphans a pointer (move+stamp), and long-lived UI — modeless dialogs, pinned cards, a 220 ms debounce — keeps acting on a document that is gone. One openDocument() that owns every member, plus a monotonic docGen_ that stale views compare against, retires four findings at once. 6. LIMITS ARE MAGIC NUMBERS THAT QUIETLY BECOME SEMANTICS. 200, 3, 2, LIMIT 1, lastAt(64), qBound(0,…,2): a performance cap becomes a claim about the world (200 of 200), a buffer size becomes a memory-safety boundary, a clamp silently downgrades a user's choice. Every literal cap needs a name, a disclosed remainder, and a clamp at the consuming end. 7. TESTS PIN SUBSTRINGS AND HAPPY PATHS, AND SOMETIMES TEST A DIFFERENT IMPLEMENTATION ENTIRELY. outline_smoke covers allcore::extractOutline while the app runs extractSaBcad; glossary_smoke covers GlossaryStore while the pane bypasses it; the openFile selftest routes through the correct path so the bypass passes; the BDRC test asserts the HTML contains a URL rather than that clicking dispatches it; the honesty sweep runs over entryHtml only. And no failure branch is reachable at all — g_harnessRun makes save dialogs return empty, so not one write-failure path has ever executed under test. Add a harness that can inject an unwritable destination, and assert contracts (the tier appears, the count is the real count, the cursor did not move) rather than the presence of strings.
