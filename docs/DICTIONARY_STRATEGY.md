# The ALL/ACIP Tibetan–English–Sanskrit Dictionary — strategy dossier
*(Adam's directive, 2026-08-12: "scour the web… find the best option
for bringing an ALL/ACIP Tibetan-English-Sanskrit glossary/dictionary
into view." Second only to Geshe Michael defining the terms himself.)*

## The governing insight

The decisive facts are **copyright clocks and licenses**, not
websites. Everything divides into four lanes:

1. **Already licensed to the world** — ingest now, attributed.
2. **Public domain by the calendar** — ingest, and AI-translate
   Tibetan-Tibetan definitions into English (our translation of a
   PD source is ours; labeled AI, never HGM).
3. **Copyrighted, licensable** — ask; pay if reasonable (Duff).
4. **Copyrighted, circulating anyway** — the de facto "free"
   versions of modern works are NOT free de jure. We do not ship
   them. Link-out only.

  partner APIs, but the full export (dict/definitions/synonyms/
  Sanskrit, 73k rows) survives as clean CSV in Christian Steinert's
  public data folder — and the LICENSE (CC-BY 4.0) comes from
  84000's own Terms of Use table, independent of the mirror.
  24,576 terms now render in the app, attributed, with links back
  to each 84000 entity page.
- **Steinert's `_input/dictionaries/public`** is the richest single
  index of digitized Tibetan dictionaries anywhere (68 files):
  Hopkins family, Rangjung Yeshe, Ives Waldo, Jim Valby, Dan
  Martin, Negi's Tib-Skt (23MB!), ITLR, Tshigdzod, Golden Mirror,
  Dungkar, Jäschke scan, Das scan-index… His README is explicit:
  *data copyright stays with the respective authors* — presence in
  the repo is NOT a license. Each candidate needs its own
  verification. Immediately promising after verification:
  **Jäschke 1881 (PD)**, Hopkins (UMA's stated distribution terms),
  ITLR and TibTermProject (check terms), Rangjung Yeshe / Waldo /
  Valby (permission via Tsadra, already on the survey list).
- **Geshe Chodrak: PD CONFIRMED (researched 2026-08-12).** Buryat
  Mongol scholar, 1898–1972; brda dag ming tshig gsal ba, Lhasa
  1946, compiled with Gendun Chophel's assistance. China life+50 →
  public domain since 2023-01-01. Etext routes, best first:
  (1) OpenPecha/Esukhia corpus; (2) the existing iOS app's maker
  (App Store id602452248 — a digitization exists); (3) our own OCR
  over the BDRC scans with the shipped BDRC models + review — the
  self-reliant lane. Then: AI-translate the native definitions
  (lane 2's flagship).
- **DSAL (U. Chicago)** hosts digitized Das — an alternative
  text source to the PKTC edition (verify current terms).

3. **Sanskrit spine** — LC (have) + Mahāvyutpatti (have) + Negi

   project), Jäschke 1881.

   a. **Working Glossary** — senses/POS/q.v. from LC+Hopkins
      comparanda (RUNNING; 45-entry pilot done).
   b. **AI-translation of PD Tibetan-Tibetan definitions**
      (Geshe Chodrak first when text lands) — "translated by AI
      from a public-domain native definition" is a tier above
      composed glosses: the CONTENT is a Tibetan lexicographer's,
      only the English is machine.
6. **Licensed crowns** — Illuminator + SCD per-seat (asked), 84000
   TM (asked), RY/Waldo/Valby via Tsadra (queued).
7. **The Approval pipeline** upgrades any of it to human-approved —
   and Geshe Michael's own rulings, whenever he gives them, replace
   everything beneath.

## Never

- Paraphrasing copyrighted dictionaries (Illuminator, Golden
  Mirror, Tshigdzod) — derivative infringement, and beneath us.
- Shipping "everyone-has-it" files without a license.
- Letting any AI text near Geshe Michael's tier.
