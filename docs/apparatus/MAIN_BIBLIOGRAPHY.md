# MAIN Bibliography — the official shared entry bank

> **Official tier.** This document is compiled ONLY from Mixed Nuts
> translations that have been published and 100% approved by Geshe
> Michael Roach (Adam's ruling, 2026-08-06, refining STD-008). It is
> regenerated by `tools/build_main_apparatus.py` when a new volume is
> released — never edited by hand, and never fed from working drafts.
> Translator-created candidates await publication in the app's
> pending queue and are not part of this document.

**138 entries** from the released volumes; 118 carry ACIP catalog numbers (these key the entries to input files and BDRC scans). Entries appear verbatim as published; the same work cited in two volumes appears under each (per-volume numbering is part of the published citation).
