# Draft — to BDRC (OCR model licensing)
*(for Adam to review, personalize, and send; BDRC contact page / help@bdrc.io)*

Subject: License of the tibetan-ocr-app model weights

Dear BDRC team,

I direct software development for the Asian Legacy Library (ALL) /
Asian Classics Input Project (ACIP) — some of whose transcriptions,
we are honored to see, contributed to your OCR training data.

We are building a desktop workbench for Tibetan translators and would
like to integrate your Tibetan OCR beyond the hand-off level: running
the released models (Betsug, Drutsa, Modern, Woodblock,
Woodblock-Stacks) in-process via ONNX Runtime, always as a
user-triggered step with output clearly marked unverified.

The application code's MIT license is clear, but we could not find an
explicit license statement covering the model weights themselves
(described as open access on the BDRC/OpenPecha Hugging Face
accounts). Could you confirm the weights' license, and whether
bundling or first-run downloading them inside a freely-distributed
desktop tool is within your intended use? We would of course credit
BDRC prominently wherever the OCR appears.

We already link every Derge/Lhasa text in our library to your scans
via BUDA and the IIIF API — thank you for that infrastructure.

Adam Andrade
Asian Legacy Library
