Subject: License clarification: glossary + translation-memory data

Dear 84000 team,

I direct software development for the Asian Legacy Library (ALL) /
Asian Classics Input Project (ACIP). We are building a desktop
translation workbench for Tibetan translators, and your published
glossary and translation-memory data would be a superb reference layer
in it — always displayed with attribution as 84000's work, never
merged into our own translation layers.

Before ingesting anything we want to be certain of the terms. We find
two statements that appear to differ:

- your Terms of Use page describes the glossary, metadata, and
  translation memory as CC BY 4.0;
- the README of the data-translation-memory repository on GitHub
  states CC BY-NC-ND 3.0.

Could you confirm which license currently governs (a) the glossary
export and (b) the translation-memory TMX files, and whether import
into a freely-distributed desktop tool (with attribution and a link
back to 84000) is within your intended use?

With appreciation for the extraordinary resource you have built,

Adam Andrade
Asian Legacy Library
