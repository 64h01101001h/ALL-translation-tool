Diamond Cutter Translation Tool — daily digest, Monday 8 September 2026

Headline. Adam paused the dictionary-alignment campaign and redirected the
project toward a public release in about two weeks; by end of day the whole
application had been inventoried function by function, and the release plan is

What got done

- Alignment campaign brought to a clean stopping point. Course 5
  (Abhidharmakosha IV with Gendun Drup’s commentary) reached 165 of 511
  segments aligned, every landing passing the full 17-gate battery. Five more
  text errata in the source files were confirmed by an independent skeptic
  pass and filed (the register now holds 182). The campaign ledger records
  exactly where work stopped and what is still open for Geshe Michael’s
  ruling.
- Reading pane improvement. The document’s file name and folder now appear
  along the top of the Overlay reading pane, so a reader with several volumes
  open can see which text is showing. Built, self-tested, committed.
- Release plan written (docs/RELEASE_PLAN_2026-09.md): a two-week path — week
  one, a person walks every function of every pane and marks it ship / hide /
  fix / relabel, while the licence, defect-intake and update-channel questions
  are settled in parallel; week two, fixes, the gated press, a clean-Mac test,
  and the first releases on GitHub.
- Weekly dictionary updates designed. Adam’s intent is to publish an updated
  dictionary every week after release. The plan specifies a data release on
  GitHub with a small manifest file, and inside the app a daily check, a
  desktop notification when a new dictionary exists, and a one-click install
  that verifies the download before anything is replaced. It builds on the
  import path the app already has, which the audit found needs hardening
  first.
- The audit itself. Twenty-nine inventories were generated by reading the
  source, covering all 22 panes plus the menus, settings, help and search
  palette: roughly 700 user-visible functions, each with its code location,
  whether an automated test covers it, and its risks. About 60% have no
  automated test today. That list is what the release walk works from.
