# PAYLOAD_MANIFEST.txt — the machine-readable manifest of everything the
# press stages into a DMG.  It is the SOURCE the press stages FROM and the
# SET the gate inspects AGAINST: tools/manifest_check.py drives the press's
# data-dir list from this file, prunes data/extracted to it, and fails the
# press on any staged path this file does not name.
#
# Written 2026-08-23 for SQA BUILD-4 (the L2 gate passed on a keyword and
# never opened the payload) and BUILD-5 (payload the notices called "NOT
# redistributed" was in the DMG).  Before it, L2 credited a whole 102 MB
# directory because the unrelated string "84000" occurred in the notices.
#
# Columns are separated by ' | '. No quoting; no field may contain
# a '|'. Lines beginning with '#' are comments.
#   mode      both / team / drop
#             both = ships in team AND market DMGs
#             team = TEAM DMG ONLY; a market press that finds it FAILS
#             drop = present in the repo tree, deliberately NOT staged.
#                    tools/manifest_check.py --prune-extracted removes these
#                    from the staged data/extracted tree and prints each one.
#   status    ok / itemise / gated
#             ok       = terms recorded and settled
#             itemise  = shipping under SHIP.md's blanket "data/extracted:
#                        SHIPS-WITH-ATTRIBUTION, pending the per-file
#                        itemization"; the per-file terms are NOT yet recorded
#             gated    = SHIP.md names a human decision still open for it
#             A market press FAILS on any staged `itemise` or `gated` row.
#             A team press prints them as notes and continues.
#   path      relative to the DMG root.  A trailing "/" covers the whole
#             subtree.  "*" globs within one path component.
#   licence   SPDX id where one is recorded, else the recorded status phrase.
#   anchor    a substring that MUST occur in OPEN_SOURCE_NOTICES.md, or "-"
#             for the files that ARE the licence/notice documents.
#   provenance  where the licence claim comes from, so a reader can check it.
#
