# Diamond Cutter Translation Tool — Install & Quick Start

*One page. No technical knowledge required.*

## Before you start — will it run on your Mac?

You need **an Apple Silicon Mac (M1, M2, M3, M4 or later) running
macOS 26 or later**.

To check: Apple menu → About This Mac. If the Chip line says "Intel",
this build will not run on your machine at all — tell your coordinator
rather than trying. If the macOS version is older than 26, update
first.

There is no error message for either case: the app simply will not
open. That is why this section is here.

## Installing (three steps)

1. **Open the DMG** you were given — double-click it. A window
   appears with two things in it: **Diamond Cutter Translation Tool.app** and a
   folder called **Diamond Cutter Tool Data**.

2. **Drag BOTH of them, together, to the same place.** They must sit
   side by side — the app finds its dictionary by looking for the
   "Diamond Cutter Tool Data" folder right next to itself. Your Applications
   folder is the recommended home, but anywhere works as long as the
   two stay together.

3. **Eject the DMG** (click the eject symbol beside its name in the
   Finder sidebar). You're done installing.

## First launch

On a Mac that has never run the tool before, don't double-click the
first time. Instead, **right-click (or Control-click) the app and
choose "Open"**, then confirm. macOS asks this once because the team
copy isn't signed through the App Store; after that first time, the
app opens normally forever.

## One-time setup (two minutes)

Open **Settings** (View menu → Settings…, or ⌘, on a Mac) — or use
the setup fields at the top of the **Community → Propose** pane;
they are the same settings in both places. Enter:

- **Your name** — stamped on any proposals you file, so the
  authority knows who is asking.
- **The shared proposals folder** — the team folder (for example,
  the team Dropbox) your coordinator points you to. This is how
  proposals travel to the authority: no accounts, no server, just a
  shared folder.

## Your first ten minutes

1. Click the **Read** tab, then **Library** inside it. The preserved
   canon — nearly 9,000 texts of the current public releases — is already there.
2. **Double-click any text.** It opens in the Overlay, the flagship
   reader, clean and unshaded.
3. **Click any word.** The longest phrase the dictionary knows at
   that spot lights up in gold, and its card appears below: the
   quality tier, Geshe Michael Roach's actual renderings course by
   course, and the reference layers — each clearly labeled as
   reference.
4. **Click the same spot again** and the highlight steps down to the
   next shorter phrase inside — dropping a particle at a time —
   until you reach the single word. The card follows every step.
5. In the Display panel, switch **"text as"** to Tibetan script to
   read in native script.

That is the heart of the tool. Everything else — translating,
searching, Sanskrit, drills, input work — lives in the six workflow
tabs across the top, and the Help menu ("Diamond Cutter Help & Tutorials…")
has a searchable tutorial for every pane.
