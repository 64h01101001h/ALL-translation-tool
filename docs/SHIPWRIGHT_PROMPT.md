## PART I — STANCE

**§1. Shipping is a truth test.** Everything the five rings built —
honesty grammar, failure voices, gates, constitution — faces its final
audience: someone who never read a ledger. v1.0 means: a person at an
input center in another country double-clicks a DMG and the tool tells
the truth from the first pixel to the last license line.

**§2. Convergence discipline.** No new features enter v1.0 scope.
Every open item gets one of three stamps: SHIPS (finish it), DEFERRED
(named in the roadmap with a reason), or DROPPED (with a ruling).
Adam's sign-off closes each scope decision; GMR's blessing closes the
data-facing surfaces. The engine may propose; only humans stamp.

**§3. The law stack holds.** CLAUDE.md honesty rules > the constitution
(suite 60) > the five prompts' settled rulings > this document. The
press's three gates plus the battery are the floor for every RC.

## PART II — TRACK L: LEGAL/LICENSE CLEARANCE (P0 — can BLOCK shipping)

**L1. The distribution manifest.** Inventory EVERY byte the DMG ships:
app binary, fonts, dictionaries, data layers, models, caches. For each:
source, license, redistribution terms, attribution requirement, and the
verdict SHIPS / SHIPS-WITH-ATTRIBUTION / MUST-REMOVE / GATED-ON-GRANT.
Known red flags to run down first:
- BDRC OCR models are CC BY-NC ("with permission" noted in-app) — NC
  is incompatible with commercial market distribution: either the
  models move to a user-downloads-them-personally flow, written
  permission is banked, or they are removed from the DMG.
- TibetanDictionary.dic and THL thl.wrd/thl.def carry standing "CHECK
  LICENSING before shipping" flags from CLAUDE.md — resolve or remove.
- The HGM release itself: Adam/ACIP's own data — confirm the release
  package's redistribution stance in writing (one line from Adam).
- Verify the good citizens surface their terms: 84000 CC BY, rKTs
  CC BY, Monlam Apache-2.0, tibetan-spellchecker CC0, OFL fonts,
  Das/Jäschke public domain, vendored code (SQLite PD, diff-match-
  patch Apache-2.0, Qt LGPL implications of the deploy mode).
**L2. The credits surface.** One About/Licenses screen assembled FROM
the manifest (never hand-maintained twice), plus a LICENSES file on the
DMG. Qt LGPL compliance notes included. The constitution gains a rule:
a data layer without a manifest entry fails the battery.

## PART III — TRACK D: DISTRIBUTION REALITY

**D1. The virgin-Mac drill.** The cold-start rig grows up: a clean
account/machine simulation of the FULL first contact — mount DMG, drag
to Applications, Gatekeeper's actual verdict, first launch, welcome,
first lookup. Every rough edge is a finding.
**D2. Signing & notarization.** Gated on Adam's Apple Developer ID
($99/yr — his call). Build the pipeline NOW (codesign + notarytool
steps in the press, skipped-with-notice when no identity is present)
so the day the ID exists, the press notarizes. Until then the README
and Help carry the right-click-open instruction honestly.
**D3. Versioning to 1.0.0.** The VERSION file, About, DMG name, git
tag, and CHANGELOG move together via a release script (S3 absorbed
here). RC builds are named 1.0.0-rc.N; the blessed-shots baseline is
tagged with each RC.
**D4. The update path.** v1 ships with a manual check: an in-app
"check for updates" that reads a VERSION endpoint (or is honestly
absent with a documented re-download path). No silent auto-update.
