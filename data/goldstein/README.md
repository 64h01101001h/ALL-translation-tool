# Goldstein honorific findings (derived data only)

`honorific_findings.tsv` — honorific-register findings for which
Melvyn Goldstein's *Essentials of Modern Literary Tibetan* (University
of California Press, 1991) was consulted as the reference source.

**The book's text is deliberately NOT in this repository.** A text
extraction (25,304 lines) was used in-house during the work and was
removed from the tree and from git history on 2026-08-26: the book is
in copyright, and a public repository is redistribution. The factual
findings remain.
