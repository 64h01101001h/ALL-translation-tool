# C05:319–321 evidence interface

Paths below are relative to this batch unless explicitly prefixed `semantic-review/`. The actual byte-preserved source-to-copy mapping is the **list** `semantic-review/original-to-copy-manifest.json`: each record has `original`, `copy`, `sha256`, `bytes`, and historical Git snapshots additionally have `original_git_commit`, `repository_relative_path`. Resolve `copy` relative to `semantic-review/`. A `.bin` copy of a gzip is the original compressed bytes, with the extension changed for the landing whitelist. Do not infer formats from every copied extension.

- `tibetan/{seq}/decisions.json`: object with `producer`, `source_origin_git_commit`, `range_convention`, `spans`, `eng_order`, `material_omissions`, `source_evidence`, `lexical_evidence`. A span has `id,d,tib,eng,seq,tib_range,eng_range,rationale,parent,source_function`.
- `english/{seq}/decisions.json`: object with `producer`, `source_origin_git_commit`, `source`, `range_convention`, `spans`, `omissions`, `eng_order`. A span has `id,d,tib,eng,seq,tib_range,eng_range,rationale,parent_id,english_whole_word_occurrence`.
- `reconciled/{seq}/final-decisions.json`: object with `producer`, `source_origin_git_commit`, `range_convention`, `spans`, `eng_order`, `material_omissions`, `complete_unwrapped_ranges`. Span fields are the seven tuple/range fields plus `rationale`, `english_whole_word_occurrence`, `selected_from`, `parent_id`, `source_function`; `selected_from` has `angle,original_id`. `complete_unwrapped_ranges` has `wylie,english`.
- `reconciled/{seq}/original-dispositions.json`: object with `seq,spans,original_omissions,coverage`. Each span disposition has `angle,original,original_complete_decision,decision,final_ids,reason,final_rationales`. Canonical original tuples live in `original`; the complete original rationale is in `original_complete_decision`. `final_rationales` maps final IDs to text. `final_ids` can be empty or contain several IDs. Omissions are separate records, not null spans.
- `reconciled/{seq}/final-ordered-tuples.json`: object with `seq,source_order,english_top_level_order,english_order_with_members`. `source_order` is a list of seven-key tuples. The other two lists contain span IDs.
- `semantic-review/original-resolved-spans.json`: list of six objects with `angle,seq,spans`, where every item in `spans` has exactly `seq,id,d,tib,eng,tib_range,eng_range`. `semantic-review/resolved-spans.json` is a flat list of 85 of those exact seven-key tuples in spec order. Ranges are zero-based, half-open Unicode character offsets in the complete original fields; null English has a null range.
- `semantic-review/original-decision-review.json`: flat list of 163 objects with `seq,angle,original,original_decision_reviewed,reconciler_disposition,final_ids,independent_verdict,independent_reason` and, for a challenged decision, `finding_id`. `semantic-review/span-review.json`: list of 85 seven-key resolved records plus `verdict,independent_reason,source_checked,canonical_native_resolver,source_and_english_occurrences_checked_in_full_clause`, optionally `finding_id`. `semantic-review/original-omission-review.json` is a separate list of 22 original omission decisions.

The original lexical evidence files are **lists**: `tibetan/evidence/full-lexical-evidence.json` (47), `tibetan/evidence/supplemental-full-lexical-evidence.json` (20), `english/evidence/lexical-evidence.json` (56), and `english/evidence/supplemental-lexical-evidence.json` (11). Records have `term,query,master_records,spine_entries,count`. Tibetan `query` is an object with `field,equals`; English `query` is a scope description string. Each master record has `collection,index,entry`. The collected main helper loops enumerate `unified_entries`, `curated_entries`, `glossary_entries`; the semantic reviewer independently checks **all three named collections** for all 134 claims and proves exact complete-object equality. This is batch-specific evidence, not a rule that every query elsewhere covers all three collections. Empty results are preserved and `count` counts master objects, not corpus occurrences or SQL dictionary rows.

`semantic-review/evidence/master-complete-objects.json` is an object keyed by `collection/index`, with complete `{collection,index,entry}` values; indexes are zero-based within that named master collection. `semantic-review/evidence/master-term-index.json` maps each of 77 terms to `{master_keys,spine_rows}`. These `spine_rows`, and original lexical `spine_entries`, come from the SQLite **entries** table. Their `raw` is a JSON string containing a dictionary entry. It has no obligation to contain `course,seq,english`. Dictionary `hgm_gloss` is itself JSON text in SQLite; complete master `hgm_gloss`/`hgm_glosses` are arrays. `evidence/original-lexical-checks.json` is a list of 134 checks with `original,index,term,count,spine_count,complete_master_and_spine_records_exact`.

The actual SQL corpus claims are the lists `tibetan/evidence/corpus-queries.json`, `tibetan/evidence/partial-parallel-queries.json`, and `english/evidence/corpus-queries.json`. Their `sql,params,rows,count` preserve the query itself; auxiliary metadata differs by producer. Only these corpus query rows come from **corpus_segments**. They have `id,course,seq,acip,wylie,english,raw`, with `raw` a JSON string of the source corpus object. The independent list `semantic-review/evidence/independent-query-proofs.json` preserves all 36 actual `sql,params` pairs and `count,row_ids,external_corpus_indexes,C16_P1_TCS_row_ids`, linked by `original,index`. A complete-field equality search, a leading-phrase search, and a broad lexical substring search have different scopes; retain the SQL predicate and parameters when interpreting a zero or positive result.

`semantic-review/evidence/corpus-complete-objects.json` maps string SQLite corpus IDs to `{spine,external_corpus_index,external_corpus_record}` for 63 complete records. The full external `full_parallel_corpus_v32.json.gz` decodes to a **list of 42199 objects**, not a mapping or a dictionary master collection. `external_corpus_index` is zero-based; `id - 1` equality has been proved for these material records in this exact archive, and is not a universal indexing contract. `semantic-review/evidence/independent-complete-source-context.json` is a list of 15 complete SQLite corpus rows for C05:313–327. Repeated semantic mechanics use these complete indexed records and actual prior queries; the 249 MB SQLite file is identity-bound rather than copied.

`review.json` is an object under `c05-independent-semantic-review-v1`; `segments` is a list and `open_findings` is always a list. `freeze.json` is an object whose `files` is a dictionary of relative paths to `{bytes,sha256}`. Source origin through 312 and actual through-318 acceptance receipt are distinct fields and distinct evidence.
