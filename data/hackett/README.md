# Hackett honorific-verb findings (derived data only)

`honorific_verbs.tsv` — honorific-verb pairings derived during the
honorific-register work, with Paul Hackett's *A Tibetan Verb Lexicon*
(Snow Lion, 2019) consulted as the reference source.

**The book's text is deliberately NOT in this repository.** An OCR
working copy (111 pages) was used in-house during extraction and was
removed from the tree and from git history on 2026-08-26: the book is
in copyright, and a public repository is redistribution. Factual
findings (which verb pairs with which honorific) are not the book's
expression and remain.

If deeper work on this source resumes, consult a purchased copy.
