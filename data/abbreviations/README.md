# Tibetan orthographic abbreviations (bskungs yig) — banked source

`tibschol_abbr.csv` — the abbreviations table of the ERC project *The Dawn
of Tibetan Buddhist Scholasticism (11th–13th c.) (TibSchol)*, Austrian
Academy of Sciences (ERC grant 101001002), compiled by Rachael Griffiths;
136 orthographic abbreviations found in the project's manuscript corpus,
each with EWTS + Unicode for both the abbreviated and expanded forms.

**License: CC0 1.0 Universal** (LICENSE-CC0; repo
github.com/ERC-TibSchol/abbreviations, DOI 10.5281/zenodo.10450652,
retrieved 2026-08-07). The project asks for a reference to the repository
and the rKTs project when the files are used — honored here and in-app.

Scope note (from Wilson App. 2, verified against the book 2026-08-07):
these are ORTHOGRAPHIC squeezes (bskungs yig — ཁྱདར for ཁྱད་པར, the dot
disappears). Wilson's OM dot instead marks the surviving dot inside a
SYLLABIC contraction (bsdus tshig — རྣམ་ཤེས for རྣམ་པར་ཤེས་པ), which
needs a bsdus-tshig table this file does not provide; the OM dot stays
open until one with a clear license exists (rKTs' 3,000+ list is the
candidate — license still unverified).

In-app use: the Overlay click card recognizes these forms (by EWTS and by
Unicode rendering) and shows the expansion as a labeled reference line —
the natural companion to the syllable-legality red wave, which such forms
trigger by design (they are legal abbreviations, not typos, and the card
now says so). Display only; never corpus-bound, never auto-expanded.
