# Manual of Authentic Tibetan — findings (derived data only)

`honorific_findings.tsv` — honorific findings for which Tenzin
Choephel's *Manual of Authentic Tibetan* was consulted as the
reference source.

**The book's text is deliberately NOT in this repository.** A page
extraction was used in-house and was removed from the tree and from
git history on 2026-08-26: the book is in copyright, and a public
repository is redistribution. The factual findings remain.
